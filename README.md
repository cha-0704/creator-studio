# 🎰 로또 6/45 모바일 원페이지 라이브 추첨기 & 빅데이터 분석기 (Lotto Live)

360도 회전 원심력 물리 엔진을 적용한 모바일 최적화 로또 번호 추출 및 동행복권 역대 회차 통계 분석 웹 애플리케이션입니다.

---

## 📁 프로젝트 파일 구성

- **`index.html`**: 반응형 원페이지 구조 (3D 회전 추첨기, 역대 회차 검색, 전국 명당 리스트, 애드센스 슬롯, 보관함 모달)
- **`style.css`**: 스티치(Stitch) 기반의 모바일 다크 골드/네이비 테마 및 3D 입체 구체 스타일링
- **`app.js`**: 360도 회전 캔버스 물리 시뮬레이션, 1~10게임 일괄 추출, 역대 회차 검색, 명당 지도 연동, 텍스트/CSV 파일 다운로드 엔진

---

## 🚀 스마트폰 / PC에서 실행하는 방법

1. **로컬에서 바로 실행**:
   - `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등 브라우저로 엽니다.

2. **내 스마트폰에서 언제든 접속할 수 있게 무료 배포하기 (추천)**:
   - **GitHub Pages**: 이 폴더의 파일 3개를 GitHub 리포지토리에 올린 뒤 `Settings ➜ Pages ➜ Deploy from branch` 선택.
   - **Vercel / Netlify**: 폴더를 드래그 앤 드롭하는 것만으로 10초 만에 무료 웹사이트 URL(예: `https://my-lotto.vercel.app`) 생성 가능.

---

## 💰 구글 애드센스(Google AdSense) 연결 방법

1. 구글 애드센스 승인 후 발급받은 게시자 ID(`ca-pub-XXXXXXXXXXXXXXXX`)를 준비합니다.
2. `index.html`의 9번 라인 부근 `<head>` 영역에 스크립트를 삽입합니다.
   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-YOUR_ID" crossorigin="anonymous"></script>
   ```
3. `index.html` 하단의 `adsense-banner-container` 주석을 해제하고 광고 단위 코드를 넣으면 배너가 자동 노출됩니다.

## 🌟 핵심 기능 요약

1. **🎯 3D 원터치 회전 추첨기**:
   - [돌리기]를 누르면 유리통이 시계방향으로 고속 회전하며 45개의 공이 360도 전 방향으로 휘몰아치며 충돌합니다.
   - [멈추기]를 누르면 서서히 감속하며 6개의 번호가 순차적으로 슬롯에 떨어집니다.
   - 1게임부터 10게임까지 선택 추출 지원.
2. **📥 파일 저장 & 보관**:
   - 추출 후 **[파일저장]** 버튼 터치 시 `로또_행운번호_YYYYMMDD.txt` 파일로 즉시 다운로드.
   - **[보관]** 버튼 터치 시 브라우저 내부 보관함 저장 및 CSV 다운로드 지원.
3. **🔍 역대 회차 검색 & 데이터 분석**:
   - 1회~1160회 회차 검색 시 당첨번호, 보너스 번호, 1등 당첨금 및 당첨자 수 확인.
   - 역대 최다(34, 13, 27 등)/최소 출현 번호 및 1등 번호 총합 82.4% 집중 법칙 통계 제공.
4. **🏆 전국 로또 1등 명당 판매점 리스트**:
   - 전국 1위 스파(노원구, 52회), 2위 부일카서비스(부산, 50회) 등 TOP 명당 리스트.
   - 지역별 필터 및 네이버지도/카카오맵 길찾기 연동.
